# Soul of Waifu для Linux

**[English version](README.md)**

Неофициальный порт [Soul of Waifu](https://github.com/jofizcd/Soul-of-Waifu) v2.5.1 (автор —
jofizcd; оригинал выходит только под Windows). Работает на Arch, Debian, Ubuntu, Fedora,
openSUSE и их производных.

Программа состоит из двух частей:

- **Сервер** (Docker-контейнеры): языковая модель (llama.cpp), голосовые движки (Kokoro,
  Silero, Edge, XTTSv2, Qwen3-TTS, RVC), распознавание речи (Whisper), эмбеддинги памяти и
  определение эмоций. Это та часть, которой нужна видеокарта. В саму систему из неё ничего не
  ставится.
- **Программа**: окно, Live2D/VRM, микрофон и динамики, ваши персонажи и чаты. Без torch и CUDA
  (около 1,5 ГБ). С сервером она связывается по адресу и токену, поэтому один сервер с
  видеокартой может обслуживать ноутбуки и другие компьютеры вашей домашней сети.

## Установка

```bash
curl -fsSL https://gitlab.projectmiku.cc/opensrc/soul-of-waifu-linux/-/raw/main/install.sh | bash
```

Установщик не принимает аргументов. Он спрашивает язык, показывает сводку по железу и системе,
объясняет каждый шаг и спрашивает разрешения перед всем, что меняет систему (пакеты, Docker,
NVIDIA Container Toolkit). Драйверы видеокарты он не ставит и не меняет никогда и в группу
`docker` не добавляет. Варианты:

1. **Всё на этом компьютере** — сервер и программа. Можно разрешить подключение с других
   устройств в локальной сети.
2. **Только сервер** — для других компьютеров. В конце покажет строку подключения.
3. **Только программа** — подключение к уже работающему серверу по этой строке.
4. **Удалить Soul of Waifu**.

Нужны: x86-64, около 25 ГБ свободного места для сервера (5 ГБ для одной программы),
пользователь с `sudo`. Видеокарта не обязательна, но сильно ускоряет работу; для NVIDIA сначала
поставьте проприетарный драйвер и перезагрузитесь.

### Голоса и модель

Голосовые движки и языковая модель делят видеопамять. Установщик спрашивает, какие голоса вы
будете использовать (обычные / с клонированием / с RVC), и показывает только те модели, которые
помещаются в остаток, с контекстом 16k токенов. Замеры на карте 16 ГБ: обычные голоса оставляют
модели 13,3 ГБ (до Qwen3 14B), клонирование — 9,4 ГБ, клонирование с RVC — 8,2 ГБ. XTTSv2
включается только после принятия его лицензии (Coqui CPML, некоммерческое использование).

Чтобы сменить голосовой профиль, модель или доступ из сети, запустите установщик ещё раз.
Другие модели скачивает Models Hub в программе — прямо на сервер.

## Подключение других устройств

На компьютере с сервером `sow-server pair` показывает строку подключения
(`sow://адрес:порт#token=...&fp=...`). Вставьте её в установщик на другом компьютере (вариант 3)
или в программу: *Настройки → Сервер Soul of Waifu*. Соединение шифруется собственным
сертификатом сервера, закреплённым по отпечатку, и защищено токеном: передавайте строку только
на свои устройства. Не открывайте порт в интернет; для доступа снаружи используйте VPN.

## Обновления

Когда выходит новая версия, программа показывает список изменений и обновляется одной кнопкой:
сама программа, её Python-пакеты и сервер, если он на этом же компьютере. Сервер на другом
компьютере обновляется командой `sow-server update` или сам раз в сутки, если вы разрешили это
в установщике. Если сервер старше программы, она предупредит.

## Ваши данные

Персонажи, чаты, память, настройки и API-ключи лежат в `~/.local/share/soul-of-waifu/data`,
отдельно от программы. Обновления, удаление и переустановка программы их не трогают; удаление
спрашивает про них отдельно (по умолчанию — оставить). Резервное копирование профиля в самой программе
работает как раньше.

## Команды

| Команда | |
|---|---|
| `soul-of-waifu` | запустить программу (есть и в меню приложений) |
| `sow-server status` / `start` / `stop` / `restart` | контейнеры сервера |
| `sow-server logs [speech\|llama\|gateway]` | логи сервера |
| `sow-server pair` | строка подключения для другого устройства |
| `sow-server update` | обновить сервер |

Файлы: программа `~/.local/share/soul-of-waifu/app`, данные и модели сервера
`~/.local/share/soul-of-waifu/server`, настройки сервера `~/.config/soul-of-waifu/server.env`.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| Программа пишет, что сервер не подключён | *Настройки → Сервер Soul of Waifu → Проверить*; на компьютере с сервером `sow-server status`. Если сервер переустанавливали, подключитесь заново |
| Голосовой движок серый | В подсказке написано почему: не принята лицензия или не хватает видеопамяти для выбранного профиля. Запустите установщик ещё раз |
| Не хватает видеопамяти | Другие программы на той же видеокарте (игры, генерация картинок) тоже занимают память; закройте их или выберите профиль голосов полегче либо модель поменьше |
| Нет звука / не тот микрофон | В *Аудиоустройствах* выберите устройства `default`, `pipewire` или `pulse` |
| Live2D/VRM или веб-страницы чёрные под Wayland | `QT_QPA_PLATFORM=xcb soul-of-waifu` |

Логи программы: `~/.local/share/soul-of-waifu/data/logs`; логи сервера: `sow-server logs`. Каждая
установка, обновление (в том числе из программы) и удаление пишет лог со всем выводом, выполненными
командами и вашими ответами в `~/.local/state/soul-of-waifu/logs` (токен подключения скрыт); приложите
его, когда сообщаете о проблеме.

## Чем порт отличается от оригинала

- Разделение на сервер и программу, описанное выше, с интерактивным установщиком, обновлением
  из программы и папкой данных, которая переживает переустановку.
- Исправления для Linux: импорты и таймер простоя, которые были только под Windows, пути с
  обратными слэшами, открытие папок, окна и отрисовка Live2D под Wayland, WebGL для VRM на
  NVIDIA + Wayland, выбор устройств PipeWire/PulseAudio (запоминаются по имени),
  пересэмплирование под частоту устройства вывода, моно-TTS на оба канала JACK/PipeWire.
- Редакторы и просмотрщики больше не блокируют главное окно.
- TTS: загрузка модели не съедает таймаут на фразу; высота тона RVC применяется на каждом
  запросе; обновлён Edge TTS (старый клиент Microsoft больше не принимает).
- Функции только для Windows здесь не работают: управление ПК и встроенный обновлятель llama.cpp.

Прежняя сборка «всё в одном» (всё в одном процессе, `install_arch.sh` / `install_debian.sh`)
сохранена в ветке [`classic`](https://gitlab.projectmiku.cc/opensrc/soul-of-waifu-linux/-/tree/classic).
